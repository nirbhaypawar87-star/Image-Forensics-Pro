# 🔍 Image Forensics Pro
### Advanced Digital Image Forensics and Tampering Analysis Tool

## 📌 Project Overview

Image Forensics Pro is a Python-based digital image forensics application developed using Streamlit. It helps users analyze digital images and identify potential signs of image manipulation or tampering.

The application provides various forensic analysis techniques such as Error Level Analysis (ELA), image comparison, noise analysis, metadata extraction, and SHA-256 hash verification.

It also maintains evidence integrity records and analysis history using an SQLite database.

## 🎯 Objectives

- To analyze digital images using forensic techniques.
- To identify potential image manipulation and tampering indicators.
- To extract image metadata and EXIF information.
- To compare two images and identify differences.
- To maintain image evidence integrity using SHA-256 hashing.
- To generate forensic analysis reports.

## ✨ Key Features

### 1. Error Level Analysis (ELA)
- Analyzes differences in JPEG compression levels.
- Highlights areas that may have undergone modifications.
- Generates an ELA visualization.

### 2. Image Comparison
- Compares two uploaded images.
- Calculates SHA-256 hashes.
- Identifies image similarity and differences.

### 3. Noise Analysis
- Analyzes image noise patterns.
- Examines high-frequency residuals.
- Helps identify unusual image characteristics.

### 4. Metadata Forensics
- Extracts image metadata.
- Displays image format, width, height, color mode, and file size.
- Extracts available EXIF information such as camera details and date.

### 5. Tampering Indicators
- Analyzes potential signs of image manipulation.
- Provides forensic indicators for further investigation.

### 6. Evidence Integrity Records
- Generates SHA-256 hash values.
- Stores evidence integrity records.
- Maintains evidence information using SQLite.

### 7. Analysis History
- Stores previous analysis records.
- Maintains analysis history in an SQLite database.

### 8. Forensic Summary and PDF Report
- Provides a summary of forensic analysis.
- Supports forensic report generation in PDF format.

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/nirbhaypawar87-star/Image-Forensics-Pro.git
```

### Step 2: Navigate to Project Folder

```bash
cd Image-Forensics-Pro
```

### Step 3: Create Virtual Environment

```bash
python -m venv venv
```

### Step 4: Activate Virtual Environment

For Windows:

```bash
venv\Scripts\activate
```

### Step 5: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 6: Run the Application

```bash
streamlit run app.py
```

### Step 7: Open in Browser

The application will run locally at:

```text
http://localhost:8501
```

## 🔬 Working Methodology
